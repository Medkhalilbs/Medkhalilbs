### 👨‍💻 About Me

- 🚀 **Senior Full-Stack Software Engineer & Solution Architect** with ~5 years of experience delivering robust web platforms, mission-critical enterprise systems, and distributed cloud applications.
- 🏢 **Founder & Lead Architect at [Bindev](https://bindev.site)**: Leading engineering initiatives, designing scalable microservices, and implementing resilient enterprise digital solutions.
- 🛡️ **Security-by-Design Advocate**: Specialized in building hardened web architectures with zero-trust principles, JWT / OAuth2 auth flows, Helmet security headers, API rate limiting, and automated vulnerability scanning.
- ☁️ **Cloud Native & DevOps Enthusiast**: **AWS Certified Cloud Practitioner**, orchestrating resilient containerized workloads using Docker, automated CI/CD pipelines (Jenkins, SonarQube), and modern infrastructure practices.
- 📐 **Architecture Philosophy**: Domain-Driven Design (DDD), Clean Architecture, high-throughput RESTful APIs, modular monoliths to microservices migration, and database performance tuning.
- 💡 **Passion**: Designing developer-friendly workflows, crafting pixel-perfect reactive interfaces, and engineering backend engines that withstand heavy operational traffic.
